# W5 Ollama 部署记录（模板）

## 1. 安装与拉取
- 安装方式：官网安装包
- 命令：`ollama pull qwen2.5:0.5b`

## 2. 我选的模型与理由
- 模型：qwen2.5:0.5b
- 本机内存：16 GB
- 选择理由：0.5B参数量很小，对内存要求低，CPU就可以跑，适合本地部署练习；虽然能力弱一点，但满足基础中文问答、教学助手实验，符合“内存不足换更小量化档”原则。

## 4. 术语正名
让大模型进小内存靠的是 **量化（Quantization）**；
**MCP** 另指"模型上下文协议"（第 10 周专讲），不要混用。

## 5. 排错记录
（下载慢 / 内存不足 / 服务未启动 — 各是怎么解决的）
1. 模型下载慢：使用huggingface镜像源hf-mirror加速；ollama下载慢可更换国内镜像。
2. 内存不足：选择参数量更小的模型（0.5B），使用低量化版本，关闭电脑其他占用内存软件；如果ollama跑不动，切换transformers fallback方案。
3. 模块缺失报错（No module named transformers）：在虚拟环境myenv里分开安装torch和transformers，不要把两个包放同一个pytorch源安装。
4. 服务未启动：先确认ollama后台程序运行，再执行ollama run；fallback方案不需要ollama服务，直接python运行py文件。
